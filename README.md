# Página de perfumes

Plantilla para un catálogo web de perfumes. El repositorio comienza como prototipo visual; no procesa pedidos ni pagos.

## Objetivo
Presentar productos de forma ordenada, con información clara y una experiencia adaptable a móviles.

## Estructura propuesta
```text
.
├── assets/
│   ├── images/
│   └── icons/
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── docs/
│   └── CATALOG.md
└── index.html
```

## Funciones previstas
- Catálogo de productos.
- Filtros por categoría o familia olfativa.
- Fichas con descripción y precio editable.
- Diseño responsive.
- Sección de contacto.

## Consideraciones
- Usar imágenes propias o con licencia.
- Verificar precios, disponibilidad y descripciones antes de publicar.
- No solicitar ni almacenar datos de pago en esta plantilla.
